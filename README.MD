# 🤖 AI 모의면접 서비스

***

## 📌 1. 프로젝트 개요

저희는 취업 준비생 입장에서 *실질적인 도움이 되는 서비스*가 무엇일까 고민했고,  
그 결과 **실시간 피드백이 가능한 AI 면접 플랫폼**을 기획하게 되었습니다.

***

## 🤖 2. 주요 기능

✅ **맞춤형 질문 생성**  
* 사용자의 자기소개서와 포트폴리오를 LLM(거대 언어 모델)로 분석  
* 개인 맞춤형 면접 질문을 동적으로 생성

✅ **답변 태도 분석**  
* 웹캠으로 녹화된 사용자의 답변 영상을 분석 
* 시선 처리, 표정 변화 등 비언어적 요소를 평가

✅ **종합 결과 피드백**  
* 면접 답변 내용과 태도 분석 결과를 종합하여 점수화  
* 상세 분석 리포트를 사용자에게 제공
